# Lamicare DRO Uganda Website

Official website for **Lamicare DRO Uganda** — a non-governmental, non-profit, community-based organization advancing the rights and inclusion of persons with disabilities in Uganda.

**Live structure inspired by professional NGO sites (e.g. youthsat.org style).**

## Pages
- Home
- About Us
- What We Do
- Current Projects
- Success & Impact Stories
- Gallery
- Newsletter
- Partners & Donors
- Meet Our Team
- Reports & Publications
- Get Involved
- Contact Us

## Features
- Responsive design
- Pesapal donation embed on key pages
- Full navigation with dropdowns
- Image gallery using organisation photos

## How to view
Open `index.html` in a browser, or enable GitHub Pages (Settings → Pages → Deploy from main branch).

## Donation
The site includes the Pesapal embed:
```html
<iframe width="200" height="40" src="https://store.pesapal.com/embed-code?pageUrl=https://store.pesapal.com/donateforlimacaredrouganda" frameborder="0" allowfullscreen></iframe>
```
